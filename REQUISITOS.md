# Recomendaciones y consideraciones

En este proyecto se deberá desarrollar la aplicación web con las funcionalidades
mencionadas. La aplicación web deberá ser desarrollada en el lenguaje de
programación Python y el framework Flask.

Esta entrega se realiza sobre un proveedor de nube pública, utilizando servicios PaaS.

Se requiere utilizar el siguiente stack tecnológico, con las versiones que más se
faciliten o las más recientes:

1. **Python:** lenguaje de programación.
2. **Flask:** microframework web.
3. **Flask SQLAlchemy:** extensión que agrega soporte para el ORM SQLAlchemy,
   mapeador relacional de objetos que simplifica la interacción con una base SQL.
4. **Flask RESTful:** extensión para desarrollar API REST con un patrón de diseño
   orientado a objetos.
5. **Flask Marshmallow:** integración con Marshmallow para serialización de objetos.
6. **Flask JWT Extended:** soporte para JSON Web Tokens, protección de vistas,
   creación de tokens y actualización de tokens, entre otras funciones.
7. **Werkzeug:** biblioteca de aplicaciones web WSGI.
8. **PostgreSQL:** motor de base de datos SQL de código abierto.
